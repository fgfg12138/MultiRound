# 示例剧本：AI 技术趋势分析
---
topic: AI 技术趋势分析
atmosphere: formal
totalRounds: 3
maxSpeechLength: 300
speakOrder: sequential

goal:
  type: analysis
  description: 从技术、产品、商业三个视角剖析 AI 技术趋势关键方向
  successCriteria: 三方均就资源分配优先级达成一致

host:
  name: 主持人
  style: 中立、控场、善于追问
  mode: visible

characters:
  - name: 技术专家
    role: 技术专家
    persona: 关注架构、性能与工程实现，务实但有时过于悲观
    stance: 倾向优先投资模型压缩与边缘部署
    style: 数据驱动，引用文献
  - name: 产品经理
    role: 产品经理
    persona: 关注需求、体验与商业价值，讨厌空话
    stance: 主张双轨并行，用户行为指标锚定投入
    style: 用户导向，务实
  - name: 商业分析师
    role: 商业分析师
    persona: 关注竞品、趋势与增长路径，数据导向
    stance: 强调短期可量化回报
    style: 商业思维，ROI 导向
---
（可选背景描述）
本次讨论围绕 AI 技术趋势展开，三位角色从不同视角发表观点。
